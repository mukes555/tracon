# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be welcoming, assume good faith, and keep criticism about the code. Harassment, discrimination, and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainers via the contact listed on the repository profile. Reports are handled confidentially.
