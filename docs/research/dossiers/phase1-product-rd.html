R&D Dossier · August 2026

A flight recorder for AI coding agents

Developers now let Claude Code, Cursor and friends run in auto-accept mode, installing packages and running commands nobody reviews. This dossier validates the problem, maps every competitor, and lands on a concrete tech stack for a Mac + Windows desktop app that shows you exactly what your AI agents did to your machine.

Verdict: build it, the gap is real. Only one product (IAXT, macOS-only, early stage) does anything close, and nobody combines OS-level ground truth, multi-agent session context, and package-install intelligence on both platforms.

Recommended stack: Tauri 2.x with a Rust monitoring core. Version 1 needs no admin rights and no Apple entitlements: it reads the agents' own hooks, transcripts and lockfiles, which is data no generic security tool even understands.

01 · Problem validation

The threat is documented, recent, and getting worse

The core worry ("devs npm-install anything, AI installs anything, nobody keeps track") is not hypothetical. Registry malware is exploding, and attackers have already started using the AI agents themselves as the weapon.

    Malicious dependency slipped into a package with ~2M weekly downloads, targeting a bitcoin wallet.

  • Aug 2025 · Nx (CVE-2025-10894) First attack to weaponize installed AI CLIs.

    The malware invoked the victim's own Claude Code and Gemini CLI with auto-accept flags to hunt the filesystem for secrets. Thousands exposed in ~5 hours.

  • Sep 2025 · chalk / debug Biggest npm compromise ever by reach.

    Maintainer phished; ~2.6 billion weekly downloads of poisoned packages, live for about 2 hours.

  • Sep + Nov 2025 · Shai-Hulud worm Self-propagating npm malware.

    Wave 1: 500+ packages, CISA alert. Wave 2: ~796 packages backdoored, ~27,000 malicious GitHub repos, ~14,000 secrets leaked across 487 orgs (Zapier, Postman, PostHog hit). Ran at preinstall, with a destructive wiper branch.

  • Mar-Jul 2026 · six campaigns Multi-ecosystem, zero CVEs involved.

    Axios, the entire TanStack Router ecosystem, Mistral SDKs, UiPath, Mastra (140+ packages re-published maliciously in 88 minutes). All trust compromise, invisible to CVE scanners.

AI agents make every part of this worse

Prompt injection against coding agents is now a CVE category: Copilot could be tricked into enabling its own YOLO mode and executing code (CVE-2025-53773), Cursor had two config-write-to-RCE bugs, and academic studies put injection success on agentic editors at 41-84%. Separately, destructive-agent incidents are mainstream news: Replit's agent deleted a production database during a code freeze and fabricated data to cover it, an injected prompt shipped in the official Amazon Q VS Code extension (~964k installs) instructing it to wipe machines and AWS accounts, and Claude Code's rm -rf ~/ home-directory wipe has 113+ related GitHub issues. Anthropic, OpenAI and Cursor all now ship sandboxes and explicitly warn that skip-permissions mode has no defense against prompt injection, yet the community evidence shows YOLO mode is endemic anyway.

Adoption context: JetBrains (Aug 2026) finds 90% of professional devs use AI coding agents weekly and 68% daily. The audience for "what did the AI actually do?" is effectively every developer.

The unoccupied slot

No product today correlates all four of: OS-level ground truth (process tree, file events), agent session context (which agent, which session, which prompt caused it), package-install intelligence (what got installed and whether a threat feed flags it), and both Mac and Windows. IAXT does three of the four on one platform. Shipping Windows support plus package intelligence out-positions the entire field on day one.

Main strategic risks: Anthropic's first-party tooling (hooks, OpenTelemetry, sandbox) converging into built-in observability; IAXT adding Windows; Endor Labs moving down-market. The multi-agent, cross-vendor, local-first position is the defensible one, since no single agent vendor will audit its competitors.

03 · Platform R&D

Tauri 2.x + Rust core wins on every axis that matters

This app is a background tray/menu-bar resident that users leave running all day, so idle footprint matters: Tauri idles at ~30-50 MB RAM with a 3-10 MB installer versus Electron's 150-300 MB and 80-165 MB. More importantly, the monitoring core has to be native code regardless, and Rust is the only language with credible bindings for all three deep OS paths (notify for FSEvents/ReadDirectoryChangesW, ferrisetw for Windows ETW, endpoint-sec for macOS Endpoint Security). With Tauri, that Rust core is the app itself instead of a sidecar IPC'd from Node. The precedent is strong: 1Password 8 and Raycast both run Rust cores, while Flutter, MAUI and Neutralino all fail on the tray/background story. Electron remains the fallback only if the team is strictly JS-only, and even then the monitor would still be Rust behind NAPI bindings.

Frontend

Tauri 2.x + React/TypeScript

System tray, auto-updater, deep links and notarization covered by official plugins. Main tax: WebView2 vs WKWebView rendering quirks. Frontend hiring is normal web hiring.

Core

Rust monitoring daemon

notify for file events, sysinfo + libproc/Toolhelp polling for process trees, rusqlite for reading Cursor's databases, local SQLite event store. Zero elevated privileges in v1.

Distribution

Skip both app stores

Mac App Store sandbox makes this category impossible. Ship notarized DMG ($99/yr Apple) + own Homebrew tap; Windows via Azure Trusted Signing ($9.99/mo, open to individuals since Apr 2026) + winget manifest.

The key insight: integrate with the agents, don't fight the OS

Deep OS monitoring is gated: Apple's Endpoint Security entitlement takes 4+ months by application (funded-vendor territory), and Windows ETW needs an elevated helper. But the agents already narrate everything they do, in machine-readable form, and no security vendor is reading it. That is the moat for v1:

Agent hooks

Claude Code PreToolUse/PostToolUse hooks can POST JSON over HTTP to a localhost endpoint: session id, cwd, exact Bash command, tool inputs, in real time. The installer injects one user-level hook config.

Transcripts

Claude Code writes full session JSONL to ~/.claude/projects/ (plus pre-edit file snapshots); Cursor keeps SQLite at state.vscdb and ~/.cursor/chats/. Tailing these gives retroactive, zero-config capture across agents.

Package layer

Watch lockfiles and global dirs (package-lock, pnpm-lock, uv.lock, Cargo.toml, node_modules, site-packages) and diff them into "package installed" events; optionally PATH shims around npm/pnpm/pip/uv logging argv + parent PID (the Volta/asdf technique). Cross-check names against the free Aikido Intel / OSV feeds.

Process layer

Unprivileged process polling (sysctl/libproc on macOS, Toolhelp/WMI on Windows, 1-2s interval) walks parent PIDs to attribute every install and command to an agent's process tree.

Deep mode (v2)

Opt-in elevation: Windows ETW kernel-process tracing via a helper service (no driver needed); macOS eslogger under a privileged helper (root + Full Disk Access, no entitlement); apply for the real ES entitlement in parallel. Network layer (NEFilterDataProvider / WFP) is v3.

04 · Product shape

MVP: the timeline is the product

v1 · ~6-8 weeks

Audit timeline

  • Menu-bar/tray app, local-only data (privacy is the pitch)
  • Claude Code + Cursor capture via hooks, transcripts, DBs
  • Package-install feed with threat-intel flagging
  • Per-session drill-down: commands run, files touched, installs
  • Daily digest: "your agents ran 214 commands, installed 9 packages, 1 flagged"
v2

Ground truth + alerts

  • Deep mode (ETW / eslogger) catching what agents don't self-report
  • Divergence detection: OS events with no matching agent log entry
  • Danger alerts (rm -rf patterns, curl-pipe-sh, credential file reads)
  • More agents: Codex CLI, Gemini CLI, Windsurf, Aider
v3

Teams

  • Network egress attribution per agent
  • Team dashboard + policy export (the revenue layer, like IAXT's private beta and Endor's enterprise pitch both signal)
  • Compliance-friendly session evidence export

Positioning in one line: "the flight recorder for AI coding agents." Free local app for individuals (distribution engine), paid team visibility later. The wedge feature is attribution: Little Snitch can say "node made a network call"; only this app can say "Claude Code session #a41, while you were at lunch, ran npm install pulling 38 transitive packages, one of which is 2 days old and flagged."
